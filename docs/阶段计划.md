# SmartRead Agent 阶段计划

## v0.1 项目立项与目录初始化

- 目标：确定项目方向，建立目录、文档和项目管理材料骨架。
- 主要任务：创建项目目录、README、需求说明、技术方案、WBS、版本计划、风险清单、测试计划和 Bug 记录表。
- 预期交付物：本地 Git 仓库、项目文档基础版、项目管理材料基础版。
- 对应课程价值：为软件开发实践提供项目基础，为软件项目管理提供过程证据链。

## v0.2 文本导入与摘要 MVP

- 目标：完成可运行 Android Demo。
- 主要任务：搭建 Android/Kotlin 工程，实现文本粘贴输入、示例文本、本地摘要、关键词提取和结果展示。
- 预期交付物：可运行 Demo、基础截图、第一轮测试记录。
- 对应课程价值：体现移动端开发能力和最小可用产品思路。
- 当前状态：已完成构建、APK 生成、模拟器运行、首页截图、摘要结果页截图、空文本边界测试和长文本边界测试，进入验收归档。

## v0.3 Agent 问答与知识卡片

- 目标：增强阅读辅助体验。
- 主要任务：实现 Agent 问答页面、知识卡片页面和复习题基础版生成。
- 预期交付物：功能截图、问答演示材料、知识卡片演示材料。
- 对应课程价值：体现 AI App 的交互能力和功能扩展过程。
- 当前状态：已完成代码开发、APK 构建、模拟器运行验证、V0.3 截图和 TC-007 至 TC-014 测试记录。

## v0.4 LiteRT 端侧模型集成

- 目标：加入端侧 AI 分析能力。
- 主要任务：训练轻量句子重要性模型，导出 `.tflite` 文件，在 Android 端完成推理展示。
- 当前结果：模型文件、训练脚本、Notebook、Android 结果页展示、APK 构建和模拟器截图已完成。
- 预期交付物：模型文件、模型说明、LiteRT 分析截图。
- 对应课程价值：体现移动端 AI 与端云协同能力。

## v0.5 历史记录与体验优化

- 目标：完善使用流程和演示稳定性。
- 主要任务：实现历史记录，优化 UI，修复第一轮测试问题，整理截图和 Bug 记录。
- 当前结果：已实现最近历史记录保存、历史记录页、恢复历史分析和清空历史。
- 预期交付物：较稳定 App、Bug 修复记录、测试反馈材料。
- 对应课程价值：体现迭代开发、测试管理和版本控制实践。

## v1.0 期末演示稳定版

- 目标：形成可提交和可演示版本。
- 主要任务：发布演示 APK，整理项目说明文档、PPT、截图、Gitee 材料和演示材料。
- 当前结果：已冻结功能范围，更新 Android 版本号和 App 顶部文案，整理 V1.0 说明、演示讲稿、答辩问题、项目亮点和最终提交说明；构建并归档 V1.0 Debug APK。
- 预期交付物：APK、源码、PPT、项目说明文档和最终技术课程材料包。
- 对应课程价值：完成双课程最终交付。

## V1.0 冻结说明

V1.0 不再新增云端大模型 API、用户登录、OCR、多设备同步、后端服务器、复杂数据库和语音输入。最终演示重点放在已有功能稳定串联和过程材料完整提交。
