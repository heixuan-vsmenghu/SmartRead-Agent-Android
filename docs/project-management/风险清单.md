# SmartRead Agent 风险清单

| 风险描述 | 影响 | 概率 | 应对措施 |
|---|---|---|---|
| Android 环境构建失败 | 影响工程搭建和后续开发 | 中 | 先创建最小 Demo，记录报错信息，必要时更换 Gradle 配置或网络 |
| Gradle 下载慢 | 影响开发进度 | 高 | 提前搭建环境，使用稳定网络或镜像源，避免临近提交才构建 |
| LiteRT 模型集成难度高 | 影响 AI 亮点展示 | 中 | 先完成本地摘要 MVP，LiteRT 作为 v0.4 增强功能 |
| 云端 Agent API 不稳定 | 影响问答演示 | 中 | 保留离线摘要和关键词功能，演示前准备示例文本 |
| 演示时网络不可用 | 影响云端功能 | 中 | 提供离线兜底模式，准备本地截图和录屏 |
| 小组人手较少导致任务集中 | 影响进度和测试充分性 | 高 | 明确核心开发和测试反馈分工，优先完成 MVP |
| 后期文档材料整理不及时 | 影响项目管理课程提交 | 中 | 每个阶段及时保存截图和记录，不集中到最后一天补材料 |
| APK 在不同手机上兼容性问题 | 影响真机演示 | 中 | 提前在至少一台真机安装测试，保留安装和运行截图 |
