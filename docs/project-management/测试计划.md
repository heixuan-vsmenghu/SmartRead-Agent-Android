# SmartRead Agent 测试计划

## 测试目标

确认 SmartRead Agent 的主要功能能够稳定运行，输出结果清晰，适合课程演示和提交截图。

## 测试范围

- 文本输入测试。
- 长文本测试。
- 空文本测试。
- 摘要结果测试。
- 关键词结果测试。
- Agent 问答测试。
- LiteRT 端侧分析测试。
- 历史记录测试。
- APK 安装测试。
- 真机体验测试。

## 测试分工

- 项目负责人：完成开发自测，修复主要问题。
- 测试与反馈成员：从普通用户角度进行体验测试，记录问题和建议。

## 测试记录要求

- 只记录真实测试结果。
- 未测试内容写“待补充”。
- Bug 需要写明发现日期、问题描述、严重程度、状态和修复说明。
