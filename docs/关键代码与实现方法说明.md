# SmartRead Agent 关键代码与实现方法说明

## 1. Android 应用入口

关键文件：`android/app/src/main/java/com/smartread/agent/MainActivity.kt`

`MainActivity` 通过 `setContent { SmartReadAgentApp() }` 启动 Jetpack Compose 页面。`SmartReadScaffold` 负责维护当前页面、输入文本、分析结果和历史记录状态，并把首页、Agent 问答页、知识卡片页、历史记录页串成一个完整流程。

对应代码位置：

- `MainActivity.onCreate`：应用入口。
- `SmartReadAgentApp`：Compose 根组件。
- `SmartReadScaffold`：页面状态、分析动作和导航控制。

## 2. 文本摘要与关键词提取

关键对象：`TextAnalyzer`

实现方法是先对输入文本做清洗和句子切分，再计算关键词得分，最后结合关键词命中、句子长度和句子位置选出更适合展示的句子。该方案不依赖网络，适合课堂演示和离线运行。

核心流程：

1. `analyze(rawText)` 接收用户输入。
2. `splitSentences(text)` 按中文和英文标点切分句子。
3. `scoreKeywords(text)` 统计候选关键词。
4. 根据关键词命中、长度和位置为句子打分。
5. 生成一句话总结、关键词列表和分点摘要。

## 3. LiteRT 端侧句子重要性分析

关键文件：

- `android/app/src/main/java/com/smartread/agent/SentenceImportanceClassifier.kt`
- `android/app/src/main/assets/sentence_importance_model.tflite`
- `model/train_sentence_importance_model.py`

`SentenceImportanceClassifier` 使用 TensorFlow Lite Interpreter 加载 assets 中的 `sentence_importance_model.tflite`。每个句子会被转换为 5 个特征：句子长度、关键词重合度、位置、标点提示和总结提示词。模型输出重要性得分后，页面展示得分和等级。

对应代码位置：

- `SentenceImportanceClassifier.classify(features)`：执行端侧推理。
- `SentenceImportanceAnalyzer.extractSentenceFeatures(...)`：提取 5 维句子特征。
- `SentenceImportanceAnalyzer.attachImportance(...)`：把模型结果挂到文章分析结果中。
- `LiteRtAnalysisCard`：在摘要结果页展示 LiteRT 结果。

## 4. Agent 问答与学习材料生成

关键对象：`LocalReadingAgent`

V1.0 的 Agent 问答采用本地规则型方案，不接入云端大模型 API。它会读取当前文章的一句话总结、关键词和分点摘要，再根据问题类型生成回答。这样可以避免网络、Key 和接口限流对演示造成影响。

对应代码位置：

- `answerQuestion(question, analysis)`：围绕文章内容回答问题。
- `generateKnowledgeCards(analysis)`：生成知识卡片。
- `generateQuizQuestions(analysis)`：生成复习题和参考答案。
- `AgentChatScreen`：展示快捷问题、手动提问和回答记录。
- `KnowledgeCardsScreen`：展示知识卡片和复习题。

## 5. 历史记录保存与恢复

关键对象：`HistoryRepository`

历史记录使用 SharedPreferences 保存最近 12 条分析结果，内容包括原文、摘要、关键词、句子数、字符数和保存时间。该方案足够支撑课程演示，并且比引入数据库更轻量。

对应代码位置：

- `HistoryRepository.save(context, analysis)`：保存分析结果。
- `HistoryRepository.load(context)`：读取历史记录。
- `HistoryRepository.clear(context)`：清空历史记录。
- `HistoryScreen`：展示历史列表。
- `openHistoryRecord(record)`：恢复某条历史记录并重新计算 LiteRT 结果。
