# SmartRead Agent 期末演示讲稿

## 一、项目背景

大家好，我们小组的项目是 SmartRead Agent：AI 智读助手。这个项目面向学生阅读课程资料、教材片段、技术文章和报告材料时的真实场景。很多时候，一段资料信息量很大，如果完全手工整理摘要、关键词和复习要点，会比较耗时，也容易遗漏重点。

因此我们希望做一个 Android 移动端 App，让用户把文章粘贴进去后，可以快速获得摘要、关键词、分点摘要，并进一步生成 Agent 问答、知识卡片和复习题。

## 二、项目目标

本项目的目标不是做一个复杂平台，而是完成一个可运行、可演示、过程材料完整的移动端 AI 阅读辅助应用。V1.0 期末演示稳定版已经冻结功能范围，不再增加云端 API、登录、OCR、多设备同步等大功能，重点保证现有功能稳定展示。

## 三、功能演示流程

第一步，打开 App，可以看到顶部显示 SmartRead Agent 和 V1.0 期末演示稳定版。首页提供文本输入区域和示例文本，演示时可以直接选择示例文本，也可以手动粘贴一段课程资料。

第二步，点击开始分析后，App 会展示一句话总结、关键词和分点摘要。这里体现的是基础阅读分析流程，用户可以快速把握文章主题和重点。

第三步，查看 LiteRT 端侧分析区域。App 会对文章句子进行重要性评分，并显示推理来源为 LiteRT 本地模型，说明模型文件已经随 APK 打包并在移动端本地运行。

第四步，进入 Agent 问答页。用户可以点击快捷问题，也可以手动输入问题。当前实现是本地规则型 Agent，会围绕当前文章摘要、关键词和分点摘要回答，不是脱离文章内容的闲聊。

第五步，进入知识卡片页。App 会把文章重点整理成适合复习的卡片，并生成 3 道复习题和参考答案，适合学习场景。

第六步，进入历史记录页。完成分析后，记录会保存到本地历史记录中，用户可以查看之前分析过的内容，也可以恢复历史分析或清空记录。

## 四、AI 功能说明

项目中的 AI 能力分为两部分。第一部分是本地文本处理，包括摘要、关键词、分点摘要、知识卡片和复习题生成。第二部分是 LiteRT 端侧句子重要性模型，用于体现移动端 AI 和端侧推理。

当前 V1.0 不接入云端大模型 API，这样可以保证演示不依赖网络，不需要 API Key，也避免现场接口不可用的风险。

## 五、LiteRT 端侧模型说明

LiteRT 模型输入为句子的 5 个数值特征，包括句子长度、关键词重合度、句子位置、标点提示和总结提示词。模型输出句子重要性得分，App 根据得分展示重要性等级。

受本机环境限制，训练脚本支持 TensorFlow 路径，也提供 NumPy 加 TFLite schema 的导出方式，最终 Android 工程中集成了真实的 `.tflite` 模型文件。

## 六、项目管理过程

软件项目管理课程方面，我们围绕同一个项目整理了 Gitee/GitHub 版本管理、小组开发约定、QQ 沟通记录、Leangoo 任务看板、测试计划、测试用例、Bug 记录和个人项目管理报告。

项目从 V0.1 到 V1.0 逐步推进，每个版本都有明确目标：V0.1 立项，V0.2 摘要 MVP，V0.3 Agent 与知识卡片，V0.4 LiteRT，V0.5 历史记录，V1.0 最终演示稳定版。

## 七、总结与展望

SmartRead Agent 最终形成了一个完整的移动端阅读辅助闭环：输入文章、生成摘要、查看关键词和重点句、围绕文章问答、生成知识卡片和复习题，并通过历史记录保存结果。

不足方面，当前摘要和 Agent 问答仍然是轻量本地方案，复杂长文效果有限；LiteRT 模型数据规模也还有提升空间。后续可以继续优化模型效果，升级历史记录存储方式，并在稳定条件下加入可选云端大模型增强能力。
