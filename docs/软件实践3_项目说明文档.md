# 软件开发实践（三）项目说明文档

## 一、项目概述

SmartRead Agent：AI 智读助手是一款基于 Android/Kotlin 的移动端 AI 阅读辅助 App。项目面向学生阅读课程资料、教材片段、技术文章和报告材料时理解成本较高、复习整理耗时的问题，提供文本输入、摘要生成、关键词提取、分点摘要、LiteRT 端侧句子重要性分析、Agent 问答、知识卡片、复习题和历史记录等能力。

V1.0 为期末演示稳定版。本版本不再扩展大功能，重点保证已有功能稳定串联，并整理 APK、源码、文档、截图和演示材料。

小组信息：A03 组，林立洲（121072021030）、江轩宇（121052023075），福建师范大学 2023 级软件工程 2 班。林立洲主要负责 Android 核心开发、AI 功能设计、LiteRT 集成、版本管理和文档整理；江轩宇主要参与需求反馈、安卓真机体验测试、UI 使用建议、文档校对和演示录屏配合。

## 二、主要功能

- 文本粘贴输入：支持用户输入待分析文章。
- 示例文本选择：提供内置示例，方便课堂演示。
- 一句话总结：生成文章主旨。
- 分点摘要：提取文章重点内容。
- 关键词提取：展示文章主题词。
- LiteRT 端侧句子分析：使用本地 `.tflite` 模型进行句子重要性评分。
- Agent 问答：围绕当前文章摘要、关键词和分点摘要回答问题。
- 知识卡片生成：把重点整理为学习卡片。
- 复习题生成：根据文章生成 3 道复习题和参考答案。
- 历史记录：支持保存、查看、恢复和清空历史分析。

## 三、技术路线

项目采用 Android/Kotlin + Jetpack Compose + 本地文本处理算法 + 本地规则型 Agent + LiteRT/TensorFlow Lite 端侧模型 + SharedPreferences 本地历史记录。

V1.0 不接入云端大模型 API，不提交 API Key，不依赖后端服务器，保证期末演示可以在离线或网络不稳定环境下完成。

## 四、系统架构

- 表现层：Jetpack Compose 页面，负责文本输入、按钮操作、页面切换和结果展示。
- 文本处理层：负责摘要、关键词、分点摘要、知识卡片和复习题生成。
- Agent 层：使用当前文章分析结果作为上下文，生成围绕文章内容的本地回答。
- LiteRT 推理层：加载 `sentence_importance_model.tflite`，输出句子重要性得分。
- 数据层：使用 SharedPreferences 保存最近 12 条历史记录。

## 五、核心模块

- 文本导入模块：接收用户粘贴文本或示例文本。
- 摘要模块：生成一句话总结和分点摘要。
- 关键词模块：提取文本主题词。
- LiteRT 分析模块：在摘要结果页展示端侧句子重要性评分。
- Agent 问答模块：支持快捷问题和手动问题。
- 知识卡片模块：展示概念卡片、核心观点卡片和复习卡片。
- 复习题模块：展示 3 道题目和参考答案。
- 历史记录模块：保存分析结果、进入历史记录页、恢复历史分析和清空记录。

## 六、关键代码与实现方法

主要代码位于 `android/app/src/main/java/com/smartread/agent/`。`MainActivity.kt` 负责 Compose 页面、文本分析、Agent 问答、知识卡片、复习题和历史记录；`SentenceImportanceClassifier.kt` 负责加载 LiteRT/TensorFlow Lite 模型并完成端侧句子重要性推理。

关键实现包括：

- `TextAnalyzer.analyze(rawText)`：完成文本清洗、句子切分、关键词提取、句子打分和摘要生成。
- `SentenceImportanceAnalyzer.extractSentenceFeatures(...)`：将句子转换为长度、关键词重合度、位置、标点提示和总结提示词 5 维特征。
- `SentenceImportanceClassifier.classify(features)`：使用 assets 中的 `sentence_importance_model.tflite` 执行端侧推理。
- `LocalReadingAgent.answerQuestion(...)`：基于当前文章摘要、关键词和分点摘要生成本地 Agent 回答。
- `LocalReadingAgent.generateKnowledgeCards(...)` 与 `generateQuizQuestions(...)`：生成知识卡片、复习题和参考答案。
- `HistoryRepository.save/load/clear(...)`：使用 SharedPreferences 保存、读取和清空历史分析记录。

更详细的代码说明见 `docs/关键代码与实现方法说明.md`。

## 十一、项目亮点

- Android/Kotlin + Jetpack Compose 完成移动端 App。
- 摘要、关键词和分点摘要形成基础阅读分析闭环。
- Agent 问答围绕当前文章内容，不是空泛聊天。
- 知识卡片和复习题适合学习场景。
- LiteRT 端侧句子重要性分析体现移动端 AI。
- 历史记录提升产品完整度。
- Gitee/GitHub 提交记录、阶段文档和演示材料体现持续迭代过程。

## 十二、不足与改进方向

- 摘要和 Agent 问答仍为轻量规则方案，复杂长文效果有限。
- LiteRT 模型为课程项目轻量模型，准确率仍有提升空间。
- 历史记录使用 SharedPreferences，适合小规模演示，后续可升级为 Room 数据库。
- 后续可在稳定条件下加入可选云端大模型增强能力。

## 十三、总结

SmartRead Agent V1.0 已形成从文本输入、摘要分析、LiteRT 端侧 AI、Agent 问答、知识卡片、复习题到历史记录的完整演示流程，能够支撑软件开发实践（三）课程的最终技术交付。
