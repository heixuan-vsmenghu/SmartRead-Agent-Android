# 软件实践（三）项目说明文档初稿

## 项目概述

SmartRead Agent：AI 智读助手是一款基于 Android/Kotlin 的移动端 AI 阅读辅助 App。项目面向学生阅读课程资料、教材片段和文章时理解成本较高、复习整理耗时的问题，提供文本导入、摘要生成、关键词提取、知识卡片、Agent 问答和历史记录等能力。

当前 V0.3 阶段已经完成可运行 Android/Kotlin 阅读助手 Demo，包含文本输入、示例文本、本地摘要、关键词提取、分点摘要、Agent 问答、知识卡片和复习题展示。

## 主要功能

- 文本粘贴输入：V0.2 已实现。
- 示例文本选择：V0.2 已实现。
- 一句话总结：V0.2 已实现。
- 分点摘要：V0.2 已实现。
- 关键词提取：V0.2 已实现。
- 知识卡片生成：V0.3 已实现。
- Agent 问答：V0.3 已实现。
- 复习题生成：V0.3 已实现。
- 历史记录：V0.5 计划实现。
- LiteRT 端侧句子分析：V0.4 计划实现。

## 技术路线

项目计划采用 Android/Kotlin + Jetpack Compose + 本地文本处理算法 + LiteRT 端侧模型 + 可选云端 Agent 增强。MVP 阶段优先保证本地功能可运行，后续再加入端侧模型和云端增强。

## 系统架构

系统主要分为：

- 表现层：Compose 页面，负责输入、按钮操作和结果展示。
- 文本处理层：负责摘要、关键词和复习题等基础算法。
- AI 增强层：当前已实现本地规则型 Agent，后续接入 LiteRT 模型推理。
- 数据层：后续保存历史记录和分析结果。

## 核心模块

- 文本导入模块：接收用户粘贴文本或示例文本，V0.2 已实现。
- 摘要模块：生成一句话总结和分点摘要，V0.2 已实现。
- 关键词模块：提取文本主题词，V0.2 已实现。
- 知识卡片模块：整理核心概念、核心观点和复习要点，V0.3 已实现。
- Agent 问答模块：围绕当前文本回答问题，V0.3 已实现。
- 复习题模块：根据摘要、关键词和分点摘要生成 3 道简答题，V0.3 已实现。
- LiteRT 分析模块：进行端侧句子重要性或类型分类，V0.4 计划实现。
- 历史记录模块：保存和查看历史分析结果，V0.5 计划实现。

## AI 功能设计

MVP 阶段采用本地算法完成摘要和关键词提取，保证演示稳定。V0.3 采用本地规则型 Agent 完成问答、知识卡片和复习题生成，不调用网络接口。LiteRT 部分计划训练轻量模型，对句子进行重要性分析或类型分类，并在 Android 端展示推理结果。

## LiteRT 集成计划

- 收集或自建小规模文本句子样例。
- 训练轻量句子分析模型。
- 导出 `.tflite` 模型。
- 在 Android 工程中集成 LiteRT 推理。
- 将模型结果用于摘要辅助或单独展示。

```powershell

```

APK 输出位置：

```text
android\app\build\outputs\apk\debug\app-debug.apk
```

课程演示用 APK 副本：

```text

```
