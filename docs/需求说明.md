# SmartRead Agent 需求说明

## 项目背景

SmartRead Agent 面向学生日常阅读教材、课程资料、技术文章和报告材料的场景。用户在阅读长文本时，常常需要先理解整体内容，再提炼重点、关键词和复习材料。如果完全手工整理，耗时较长，也不利于移动端碎片时间学习。

## 用户痛点

- 长文本阅读压力较大，难以快速把握主旨。
- 复习时需要重新整理重点，重复劳动较多。
- 关键词和知识点需要人工筛选，容易遗漏。
- 学生希望在手机上快速完成阅读辅助和复习整理。
- 网络不可用时仍希望有基本的本地分析能力。

## 目标用户

- 需要阅读课程资料、教材片段和文章的学生。
- 需要快速整理摘要和复习要点的学习者。
- 需要在移动端演示 AI 阅读辅助能力的课程项目使用者。

## 功能性需求

1. 文本导入：用户可以粘贴待分析文本。
2. 示例文本选择：App 内置若干示例文本，方便演示和测试。
3. 一句话总结：生成简短的文章主旨说明。
4. 关键词提取：提取文本中的重点词语。
5. 分点摘要：按条目展示主要内容。
6. 知识卡片生成：将核心概念整理成复习卡片。
7. Agent 问答：用户可以围绕当前文本提出问题。
8. 复习题生成：根据文本生成选择题或简答题基础版。
9. 历史记录：保存历史输入和分析结果。
10. LiteRT 端侧句子分析：对句子重要性或句子类型进行端侧分析。

## 非功能性需求

- 操作简单，适合课堂演示。
- MVP 功能可在无网络情况下运行。
- 长文本输入时不应明显卡顿。
- 结果展示应清晰，便于截图和汇报。
- 不保存 API Key、密码等敏感信息。
- 文档、截图和测试记录应真实可追溯。

## MVP 范围

V0.2 的 MVP 先限定为：

1. 文本粘贴输入。
2. 示例文本。
3. 本地摘要。
4. 关键词提取。
5. 摘要结果展示。

## V1.0 需求实现对照

| 需求 | V1.0 状态 | 说明 |
|---|---|---|
| 文本粘贴输入 | 已实现 | 首页输入框支持手动粘贴文本 |
| 示例文本选择 | 已实现 | 内置示例便于课堂演示 |
| 一句话总结 | 已实现 | 本地算法生成文章主旨 |
| 关键词提取 | 已实现 | 展示文章主题词 |
| 分点摘要 | 已实现 | 展示重点条目 |
| 知识卡片生成 | 已实现 | 根据当前文章生成学习卡片 |
| Agent 问答 | 已实现 | 本地规则型 Agent，围绕当前文章回答 |
| 复习题生成 | 已实现 | 生成 3 道复习题和参考答案 |
| 历史记录保存与恢复 | 已实现 | SharedPreferences 保存最近记录 |
| LiteRT 端侧句子分析 | 已实现 | `.tflite` 模型随 APK 打包，本地推理 |

## V1.0 冻结范围外功能

以下能力不纳入 V1.0，作为后续扩展方向：

- 云端 Agent 增强能力。
- 导出摘要或分享结果。
- 用户登录。
- OCR。
- 多设备同步。
- 后端服务器。
- 复杂数据库。
- 语音输入。

## 用户故事

- 作为学生，我希望把一段课程资料粘贴到 App 中，快速获得文章主旨。
- 作为学生，我希望看到关键词，方便判断文本主题。
- 作为学生，我希望摘要能分点展示，便于复习。
- 作为演示者，我希望有示例文本，避免现场输入过长内容。
- 作为项目开发者，我希望保留真实截图和测试记录，方便课程提交。
- 作为移动端 AI 项目实践者，我希望后期能集成 LiteRT 模型，体现端侧 AI 能力。
