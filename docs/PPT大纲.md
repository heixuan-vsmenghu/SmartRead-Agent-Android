# SmartRead Agent 期末 PPT 大纲

## 1. 项目标题

- SmartRead Agent：AI 智读助手
- Android/Kotlin 移动端 AI 阅读辅助项目
- 小组成员信息：待补充

## 2. 项目背景与痛点

- 学生阅读课程资料和文章时信息量较大。
- 手工整理摘要、关键词和复习材料耗时。
- 需要一个移动端轻量阅读辅助工具。

## 3. 项目目标

- 完成可演示 Android App。
- 实现文本输入、摘要、关键词和结果展示。
- 已实现摘要、关键词、Agent 问答、知识卡片、复习题和 LiteRT 端侧句子重要性分析。
- 后续扩展历史记录与体验优化。

## 4. 功能结构

- 文本导入。
- 示例文本。
- 一句话总结。
- 分点摘要。
- 关键词提取。
- 知识卡片。
- Agent 问答。
- 复习题生成。
- 历史记录。
- LiteRT 句子重要性分析。

## 5. 技术架构

- Android/Kotlin。
- Jetpack Compose。
- 本地文本处理算法。
- LiteRT 端侧模型推理。
- 可选云端 Agent 增强。

## 6. AI 功能设计

- 本地摘要算法思路。
- 关键词提取思路。
- Agent 问答上下文设计。
- 知识卡片与复习题生成逻辑。
- LiteRT 句子重要性模型：使用 5 维数值特征，在 Android 设备端完成本地推理。
