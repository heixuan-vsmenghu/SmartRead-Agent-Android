# SmartRead Agent 期末 PPT 大纲

## 1. 项目标题

- SmartRead Agent：AI 智读助手。
- Android/Kotlin 移动端 AI 阅读辅助项目。
- 小组成员信息：待人工补充真实姓名和学号。

## 2. 项目背景与痛点

- 学生阅读课程资料、教材片段和技术文章时信息量较大。
- 手工整理摘要、关键词和复习材料耗时。
- 移动端学习场景需要轻量、稳定、可离线演示的阅读辅助工具。

## 3. 项目目标

- 完成可运行 Android App。
- 实现文本输入、摘要、关键词、分点摘要和结果展示。
- 进一步实现 Agent 问答、知识卡片、复习题、LiteRT 端侧分析和历史记录。
- V1.0 冻结功能范围，形成期末演示稳定版。

## 4. 功能结构

- 文本输入与示例文本。
- 一句话总结、关键词和分点摘要。
- LiteRT 句子重要性分析。
- Agent 问答。
- 知识卡片。
- 复习题生成。
- 历史记录保存、恢复和清空。

## 5. 技术架构

- Android/Kotlin。
- Jetpack Compose。
- 本地文本处理算法。
- 本地规则型 Agent。
- LiteRT/TensorFlow Lite 端侧模型推理。
- SharedPreferences 本地历史记录。

## 6. AI 功能设计

- 本地摘要算法：句子切分、关键词覆盖、位置和长度评分。
- 关键词提取：基于文章词频和主题词筛选。
- Agent 问答：围绕当前文章摘要、关键词和分点摘要回答。
- 知识卡片与复习题：把阅读结果转化为学习材料。
- LiteRT 端侧模型：使用 5 维特征对句子重要性评分。

## 10. 项目亮点

- Android/Kotlin + Jetpack Compose 完整移动端 App。
- 阅读分析、学习卡片和复习题形成学习闭环。
- Agent 问答围绕当前文章，不做空泛聊天。
- LiteRT 体现移动端 AI 和端侧推理。
- 历史记录提升产品完整度。
- Gitee/GitHub 和项目管理材料体现持续迭代过程。

## 11. 不足与后续优化

- 摘要和 Agent 问答仍为轻量规则方案，复杂长文效果有限。
- LiteRT 训练数据规模较小，模型准确率仍可提升。
- SharedPreferences 适合课程演示，后续可升级为 Room。
- 后续可在稳定条件下接入可选云端大模型增强。

## 12. 总结

- SmartRead Agent V1.0 已形成可演示的移动端 AI 阅读辅助闭环。
- 项目兼顾软件开发实践成果和软件项目管理过程材料。
