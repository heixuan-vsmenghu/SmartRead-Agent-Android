# SmartRead Agent 期末演示脚本初稿

## 1. 介绍项目背景

大家好，我们小组的项目是 SmartRead Agent：AI 智读助手。项目面向学生阅读教材、课堂资料和文章时信息量较大、整理复习耗时的问题，希望通过 Android 移动端 App 提供轻量的阅读辅助能力。

当前演示内容后续会根据真实 App 截图和运行效果继续更新。

## 2. 介绍核心功能

计划核心功能包括文本导入、自动摘要、关键词提取、知识卡片生成、Agent 问答、复习题生成、历史记录和 LiteRT 端侧句子分析。

## 9. 总结项目价值和不足

项目价值在于把阅读、摘要、复习整理和 AI 问答结合到移动端场景中，同时保留项目管理过程材料。不足是小组人数较少，核心开发任务集中，后续需要继续优化模型效果、页面体验和测试覆盖。
