# SmartRead Agent 期末演示脚本

## 1. 开场介绍

大家好，我们小组的项目是 SmartRead Agent：AI 智读助手。这是一款基于 Android/Kotlin 和 Jetpack Compose 开发的移动端阅读辅助 App，主要面向学生阅读课程资料、教材片段和文章时整理摘要与复习材料的场景。

## 2. 功能范围说明

当前演示版本为 V1.0 期末演示稳定版。这个版本已经冻结功能范围，不再加入云端大模型 API、登录、OCR、多设备同步、后端服务器、复杂数据库和语音输入，重点展示已经完成并可稳定串联的功能。

## 3. 首页与文本输入

打开 App 后，顶部可以看到 SmartRead Agent 和 `V1.0 期末演示稳定版`。首页提供文本输入框和示例文本，演示时先选择一段示例文本，也可以手动粘贴文章。

截图：`V1.0首页_20260512.png`、`V1.0文本输入_20260512.png`。

## 4. 摘要与关键词

点击开始分析后，App 展示一句话总结、关键词和分点摘要。这里体现的是基础阅读分析能力，可以帮助用户快速理解文章主旨和重点。

截图：`V1.0摘要结果_20260512.png`。

## 5. LiteRT 端侧分析

在摘要结果页继续查看 LiteRT 端侧分析区域。App 会对文章句子进行重要性评分，推理来源显示为 LiteRT 本地模型，说明模型文件已经随 APK 打包并在移动端本地推理。

截图：`V1.0LiteRT端侧分析_20260512.png`。

## 6. Agent 问答

点击进入 Agent 问答页。可以使用快捷问题，也可以手动输入问题。当前 Agent 会结合文章摘要、关键词和分点摘要回答，不是脱离当前文章的空泛聊天。

截图：`Agent问答页_20260512.png`、`Agent快捷问题_20260512.png`、`Agent手动提问_20260512.png`。

## 7. 知识卡片与复习题

进入知识卡片页，App 会根据当前文章生成概念卡片、核心观点卡片和复习卡片，并展示 3 道复习题和参考答案，适合学生复习场景。

截图：`知识卡片页_20260512.png`、`复习题展示_20260512.png`。

## 8. 历史记录

进入历史记录页，可以看到最近分析过的文章。用户可以恢复历史分析，也可以清空历史记录。这个功能让项目从单次 Demo 更接近完整产品流程。

截图：`V1.0历史记录页_20260512.png`、`V1.0历史记录恢复_20260512.png`、`V1.0清空历史记录_20260512.png`。

## 9. 团队协作说明

本项目由 A03 组完成，成员为林立洲和江轩宇。林立洲主要负责 App 核心开发、LiteRT 集成、版本管理和材料整理；江轩宇参与需求反馈、安卓真机体验测试、UI 使用建议、文档校对和手机录屏演示。源码已同步到 Gitee 和 GitHub，便于老师复查提交记录。

## 10. 总结

SmartRead Agent V1.0 已实现从文本输入、摘要分析、LiteRT 端侧 AI、Agent 问答、知识卡片、复习题到历史记录的完整学习辅助流程。后续可以继续优化摘要算法、扩充 LiteRT 模型数据，并把历史记录升级为 Room 数据库。
