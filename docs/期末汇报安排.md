# SmartRead Agent 期末汇报安排

## 1. 汇报目标

SmartRead Agent 是 A03 组完成的 Android 移动端智能阅读助手。本次期末汇报需要让老师在有限时间内看清三件事：

1. App 具有明确学习场景，能解决长文本阅读整理的问题。
2. V1.0 功能链路完整，包括文本输入、摘要、关键词、LiteRT 分析、Agent 问答、知识卡片、复习题和历史记录。
3. LiteRT 端侧模型已经集成到 Android 应用中，可以说明模型输入、模型文件、端侧推理和界面展示。

软件项目管理类材料只作为迭代和协作的补充证据，本课程汇报的主线仍然是移动端 App、机器学习整合和运行效果。

## 5. 江轩宇视频展示内容

视频展示放在 PPT 第 16 页之后，内容按下面顺序即可：

1. 打开 SmartRead Agent 首页。
2. 选择示例文本。
3. 点击开始智能分析。
4. 展示一句话总结、关键词、分点摘要。
5. 停留 LiteRT 端侧分析区域，能看清句子重要性结果。
6. 进入 Agent 问答页，点击一个快捷问题。
7. 进入知识卡片和复习题页面。
8. 进入历史记录页面，恢复一条历史分析。
9. 回到首页或结果页结束。

播放视频时不需要重新讲一遍 PPT 内容，只需在关键位置补充一句“这里是端侧分析结果”“这里是本地 Agent 的回答”“这里是历史记录恢复”即可。

## 6. 重点问题回答参考

### Agent 是否调用 GPT API

当前版本没有调用 GPT API，也没有依赖云端大模型。项目中的 Agent 是本地规则型阅读 Agent，它基于当前文章的一句话总结、关键词、分点摘要、知识卡片和复习题，通过问题意图识别组织回答。它面向阅读辅助场景，不定位为通用聊天机器人。

### LiteRT 模型如何工作

LiteRT 模块用于句子重要性分析。系统先对文章分句，再提取句子长度、关键词重合度、句子位置、标点提示和总结提示词等特征。模型文件为 `sentence_importance_model.tflite`，放入 Android assets，运行时在手机端加载并输出重要性分数。

### 为什么使用本地方案

课程项目需要体现移动端应用和端侧机器学习整合。本地方案不依赖网络，运行更稳定，也方便说明模型输入、输出和推理流程。后续如果继续扩展，可以在本地能力稳定的基础上加入可选云端增强能力。
