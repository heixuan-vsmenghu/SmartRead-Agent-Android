# SmartRead Agent V1.0 期末演示稳定版说明

## 版本定位

V1.0 是 SmartRead Agent 的期末演示稳定版。本阶段不再继续扩展大功能，重点是冻结功能范围、完成回归构建、整理 APK、文档、截图索引、测试记录和双课程最终交付材料。

## V1.0 功能范围

- 文本输入与示例文本。
- 本地摘要。
- 关键词提取。
- 分点摘要。
- LiteRT 端侧句子重要性分析。
- Agent 问答。
- 知识卡片。
- 复习题。
- 历史记录保存。
- 历史记录恢复。
- 清空历史记录。

## V1.0 不做内容

为保证期末演示稳定性，V1.0 明确不加入以下功能：

- 云端大模型 API。
- 用户登录。
- OCR。
- 多设备同步。
- 后端服务器。
- 复杂数据库。
- 语音输入。

## 稳定版策略

- 继续保持本地可运行，不依赖网络和 API Key。
- 摘要、关键词、Agent 问答、知识卡片和复习题均围绕当前文章内容生成。
- LiteRT 模型随 APK 打包，在移动端本地执行句子重要性分析。
- 历史记录使用 SharedPreferences 保存最近记录，满足课程演示和小规模使用需求。
- 对未真实接入的实体手机流程不编写通过结论；V1.0 App 截图、Gitee 截图和 Leangoo 平台状态已按真实操作补齐。

## 构建与交付

- Android 版本号：`versionCode = 10`，`versionName = "1.0"`。
- App 顶部文案：`V1.0 期末演示稳定版`。
- V1.0 APK：`release\SmartReadAgent-v1.0-debug.apk`。
- V1.0 标签：`v1.0`。

## 后续优化方向

- 使用 Room 或 DataStore 替代 SharedPreferences，提升历史记录扩展性。
- 扩充训练数据，优化 LiteRT 句子重要性模型效果。
- 在课程演示之外，可探索云端大模型增强问答质量，但不作为 V1.0 必需功能。
