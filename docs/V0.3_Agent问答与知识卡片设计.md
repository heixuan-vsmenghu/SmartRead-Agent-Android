# V0.3 Agent 问答与知识卡片设计

当前状态：已实现并完成 Pixel_8 Android 模拟器初步验证。

## 1. V0.3 目标

在 V0.2 摘要 MVP 基础上，增加基于当前文章内容的 Agent 问答页面和知识卡片页面，使 App 从“摘要工具”升级为“AI 阅读助手”。

V0.3 仍以课程项目可运行、可演示为优先目标，不追求复杂商业化能力。当前阶段先使用本地规则型 Agent，保证无网络环境下也能完成演示。

## 2. V0.3 功能范围

必须实现：

- 从摘要结果页进入 Agent 问答页。
- 内置快捷问题按钮。
- 用户可以输入问题。
- App 根据当前文章和摘要结果生成回答。
- 支持生成知识卡片。
- 支持生成复习题。
- 支持返回摘要页。

暂不实现：

- 云端大模型 API。
- 用户登录。
- 多设备同步。
- 复杂数据库。
- LiteRT 模型。

## 3. 本地 Agent 实现思路

V0.3 先做本地规则型 Agent，不接 API。Agent 的输入包括：

- 当前原文。
- 一句话总结。
- 关键词列表。
- 分点摘要。
- 用户问题。

根据用户问题关键词判断意图：

- “主要内容 / 讲了什么”：返回一句话总结和分点摘要。
- “关键词 / 重点词”：返回关键词。
- “复习 / 考试 / 题目”：根据摘要生成 3 道简答题。
- “知识卡片 / 卡片”：把关键词和摘要整理成卡片。
- 其他问题：返回基于摘要的通用回答。

规则型回答示例：

- 用户问“这篇文章主要讲了什么？”
- App 回答：先给一句话总结，再列出 2 到 3 条重点。

## 4. 知识卡片结构

每张卡片包含：

- 标题。
- 类型：概念 / 观点 / 复习。
- 内容。
- 来源：由当前文本摘要生成。

示例卡片：

| 字段 | 示例 |
|---|---|
| 标题 | 项目管理过程 |
| 类型 | 概念 |
| 内容 | 项目管理需要关注需求分析、任务分解、进度跟踪、风险管理和测试管理。 |
| 来源 | 由当前文本摘要生成 |

## 5. 页面结构

V0.3 建议页面：

- `SummaryScreen`：摘要结果页，显示 V0.2 的摘要、关键词和分点摘要，并提供进入问答和知识卡片的入口。
- `AgentChatScreen`：Agent 问答页，包含快捷问题按钮、问题输入框和回答展示区。
- `KnowledgeCardsScreen`：知识卡片页，展示根据当前摘要生成的卡片和复习题。

页面流转：

1. 用户输入或选择示例文本。
2. 点击“开始分析”生成 V0.2 摘要结果。
3. 在摘要结果页点击“Agent 问答”或“知识卡片”。
4. 进入对应页面查看回答、卡片和复习题。
5. 用户可以返回摘要页重新分析。

## 6. 验收标准

- App 能从摘要页进入 Agent 问答页。
- 快捷问题能生成回答。
- 手动输入问题能生成回答。
- 知识卡片能展示。
- 复习题能展示。
- 空问题不会崩溃，并提示用户输入问题。
- 无文章内容时给出友好提示。

## 7. 备注

V0.3 不提交 API Key，不接入云端模型，不集成 LiteRT。后续如果时间允许，再在 V0.4 或 V0.5 讨论端侧模型与云端 Agent 的增强方案。

## 8. 实际实现说明

V0.3 实际实现采用单文件 Compose 状态切换方案，没有引入 Navigation Compose 依赖，避免增加 Gradle 风险。页面状态使用 `Screen.Home`、`Screen.AgentChat`、`Screen.KnowledgeCards` 管理。

已实现内容：

- 摘要结果页增加“问问 Agent”和“生成知识卡片”入口。
- `AgentChatScreen` 支持快捷问题、手动输入问题、聊天记录展示和返回摘要页。
- `KnowledgeCardsScreen` 支持知识卡片列表、复习题列表和返回摘要页。
- `LocalReadingAgent.answerQuestion()` 根据问题关键词返回摘要、关键词、复习重点、复习题或通用回答。
- `LocalReadingAgent.generateKnowledgeCards()` 根据一句话总结、关键词和分点摘要生成概念卡片、核心观点卡片和复习卡片。
- `LocalReadingAgent.generateQuizQuestions()` 生成 3 道简答题和参考答案。
- 未完成摘要时进入 Agent 页或知识卡片页，会显示友好提示，不会崩溃。
