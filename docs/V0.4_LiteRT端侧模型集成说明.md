# V0.4 LiteRT 端侧模型集成说明

## 目标

V0.4 为 SmartRead Agent 增加端侧 AI 分析能力：在完成本地摘要后，对文章前 5 个句子进行句子重要性评分，并在摘要结果页展示评分等级、百分比和推理来源。

## 模型与输入

- 模型文件：`model/exports/sentence_importance_model.tflite`
- 模型元信息：`model/exports/model_metadata.json`
- Android assets：`android/app/src/main/assets/sentence_importance_model.tflite`
- 输入张量：`[1, 5]`，类型 `float32`
- 输出张量：`[1, 1]`，类型 `float32`
- 特征含义：句子长度、关键词重合度、句子位置、标点提示、总结提示词

## 训练与导出

当前本机 Python 环境无法安装 TensorFlow，且网络代理阻止在线安装大依赖。为避免使用空模型或不可运行文件，V0.4 采用两步方案：

1. `model/train_sentence_importance_model.py` 优先尝试 TensorFlow/Keras Sequential 训练并通过 TFLiteConverter 导出模型。
2. 当前本机 TensorFlow 不可用时，脚本使用 NumPy 生成弱监督样本并训练同结构轻量神经网络。
3. `model/tools/TfliteDenseModelBuilder.java` 使用 TensorFlow Lite schema 和 FlatBuffers Java runtime 将训练权重写入真实 `.tflite` FlatBuffer。

训练摘要位于 `model/exports/sentence_importance_training_summary.json`，记录了模型结构、弱监督准确率和导出路径。模型元信息位于 `model/exports/model_metadata.json`，记录输入输出 shape、5 维特征、模型大小和 SHA256。

## Android 集成

- `SentenceImportanceClassifier.kt` 负责加载 assets 中的 `.tflite` 模型并执行本地推理。
- `SentenceImportanceAnalyzer` 从句子中抽取 5 个特征，并调用分类器生成评分结果。
- 摘要结果页新增“LiteRT 端侧分析”卡片，展示每个句子的等级、分数和来源。
- 如果模型加载或推理失败，App 会使用规则评分兜底，避免演示时崩溃；但正式交付以 LiteRT 本地模型为主。

## 后续验证

- 执行 `android/gradlew.bat :app:assembleDebug` 验证构建。
- 在模拟器中打开首页，输入文本并点击“开始智能分析”。
- 截取摘要结果页中的“LiteRT 端侧分析”卡片，用于课程材料归档。
