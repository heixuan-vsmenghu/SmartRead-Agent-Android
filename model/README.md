# 模型目录

本目录后续用于放置 SmartRead Agent 的模型相关材料，包括训练 Notebook、实验数据和导出的 LiteRT 模型文件。

## 目录说明

- `notebooks/`：后续保存模型训练或转换 Notebook。
- `data/`：后续保存可公开使用的小规模文本样例数据。
- `exports/`：后续保存导出的 `.tflite` 模型和标签文件。

## 后续计划

后续计划训练一个轻量文本句子分析模型，用于对文章句子进行重要性分析或句子类型分类，例如区分“概念说明”“结论句”“例子说明”“背景信息”等。模型训练完成后导出为 `.tflite` 文件，并在 Android 端通过 LiteRT 集成。

当前阶段不放置真实训练数据和模型文件，避免引入未经整理的数据或无效模型。
