# SmartRead Agent v1.0 期末演示稳定版

## 版本说明

SmartRead Agent v1.0 是课程期末演示稳定版，用于《软件开发实践（三）》和《软件项目管理》双课程提交。本版本冻结功能范围，不继续新增云端大模型、用户登录、OCR、多设备同步、后端服务器、复杂数据库和语音输入等大功能，重点保证已有功能可演示、可测试、可提交。

## 主要功能

- 文本输入与示例文本
- 本地摘要
- 关键词提取
- 分点摘要
- LiteRT 端侧句子重要性分析
- Agent 问答
- 知识卡片
- 复习题生成
- 历史记录保存、恢复和清空

## 技术亮点

- Android/Kotlin + Jetpack Compose
- 本地规则型 Agent，围绕当前文章内容回答
- TensorFlow Lite / LiteRT 端侧模型推理
- 本地历史记录，支持保存与恢复分析结果
- Gitee/GitHub 版本管理与持续迭代
