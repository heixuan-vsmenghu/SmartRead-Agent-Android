# Android 手机安装说明

## 安装步骤

1. 将 `SmartReadAgent-v1.0-debug.apk` 发送到安卓手机。
2. 在手机文件管理器、QQ 文件或微信文件中点击 APK。
3. 如果提示“禁止安装未知来源应用”，进入系统设置，允许当前应用安装未知来源应用。
4. 安装完成后打开 SmartRead Agent。
5. 确认首页顶部显示 `V1.0 期末演示稳定版`。

## 推荐测试流程

1. 打开 App。
2. 点击示例文本。
3. 点击“开始智能分析”。
4. 查看一句话总结、关键词和分点摘要。
5. 查看 LiteRT 端侧分析区域。
6. 进入 Agent 问答页，点击快捷问题或手动输入问题。
7. 进入知识卡片页，查看知识卡片和复习题。
8. 进入历史记录页，检查保存、恢复和清空历史记录流程。

## 常见问题

- 解析包错误：检查 APK 是否完整传输，可对比 `APK信息说明.md` 中的 SHA256。
- 无法安装：检查安卓版本、存储空间，以及是否允许当前应用安装未知来源 APK。
- 页面异常：重新打开 App；如仍异常，可卸载后重新安装，或清空应用数据后再测试。
- 测试反馈：请记录手机型号、安卓版本、是否成功安装、是否能完成主要流程，以及发现的问题。
