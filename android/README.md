# Android 工程目录

本目录后续用于放置 SmartRead Agent 的 Android/Kotlin 工程。

当前 V0.1 阶段只完成项目立项、目录结构、文档和项目管理材料初始化，暂不创建完整 Android 工程。下一阶段 V0.2 再由 Codex 创建可运行 Demo，优先实现文本粘贴输入、示例文本、本地摘要、关键词提取和摘要结果展示。

后续计划技术栈：

- Kotlin
- Jetpack Compose
- Android Studio
- 本地文本处理算法
- LiteRT 端侧模型
- 可选云端 Agent 增强

运行说明、Gradle 配置和 APK 构建步骤待 V0.2 补充。
