# 江轩宇手机录屏演示流程

## 录制目标

用于《软件开发实践（三）》期末综合项目展示。录屏重点是证明 SmartRead Agent V1.0 可以在安卓手机安装、打开并完成主要功能流程。建议总时长控制在 6 至 8 分钟。

## 录制前准备

1. 手机提前安装 `SmartReadAgent-v1.0-debug.apk`。
2. 确认 App 名称为 SmartRead Agent，首页顶部能看到 `V1.0 期末演示稳定版`。
3. 手机电量保持充足，打开勿扰模式，关闭会弹通知的软件。
4. 录屏前先清理一次后台应用，保证操作流畅。
5. 如果历史记录里已有杂乱记录，可以先在 App 内清空历史记录。

## 建议开场口播

大家好，我们是 A03 组，成员是林立洲和江轩宇。我们期末项目是 SmartRead Agent：AI 智读助手。这是一个基于 Android/Kotlin、Jetpack Compose 和 LiteRT 的移动端阅读辅助 App。下面用安卓手机录屏演示 V1.0 期末演示稳定版的主要功能。

## 录屏步骤

1. 展示手机桌面上的 App，打开 SmartRead Agent。
2. 停留首页 5 秒，口播说明这是 V1.0 期末演示稳定版。
3. 点击示例文本或在文本框中保留示例文本。
4. 点击“开始智能分析”。
5. 展示一句话总结、关键词和分点摘要。
6. 下滑到 LiteRT 端侧分析区域，说明模型随 APK 打包，在手机端本地进行句子重要性评分。
7. 点击“问问 Agent”，进入 Agent 问答页。
8. 点击一个快捷问题，例如“这篇文章讲了什么”或“帮我提炼复习重点”。
9. 展示 Agent 回答，说明回答围绕当前文章内容生成。
10. 返回结果页，进入知识卡片页。
11. 展示知识卡片和 3 道复习题。
12. 返回首页或进入历史记录页。
13. 展示刚才的分析记录，点击恢复历史分析。
14. 如时间允许，展示清空历史记录；如果不想破坏录屏中的记录，可以只口播说明支持清空。
15. 回到首页或结果页，结束录屏。

## 结束口播

以上就是 SmartRead Agent V1.0 的手机端演示。项目已经完成文本输入、摘要、关键词、分点摘要、LiteRT 端侧分析、Agent 问答、知识卡片、复习题和历史记录功能。源码、APK、项目说明文档、PPT 和截图材料已经整理到最终提交包中。

## 录制注意事项

- 不要提无关工具、代写过程或聊天过程。
- 不要说“这个功能还没做”，只讲 V1.0 已完成的稳定功能。
- 遇到卡顿时可以暂停重新录，不需要一次录成。
- 演示时语速放慢一点，每个页面至少停留 3 秒，方便老师看清。
- 视频文件建议命名为 `SmartReadAgent_A03组_手机演示_江轩宇.mp4`。
